# 営業・協業の管理方法（公開版）

> 公開リポジトリには、営業の**方法と匿名化した集計**だけを置きます。具体的な見込み先、連絡日時、相手の発言、提案内容は非公開で管理します。

## 初期の接点づくり仮説

| 接点の種類 | 試したいこと | 次の期限 | 状態 |
| --- | --- | --- | --- |
| Perl/CGIを扱う開発会社 | CPAN保守・CI整備の外部協力の可能性を聞く | 2026-11-25 | 未着手 |
| 既存システムの保守・移行会社 | Perlの調査・互換性確認を切り出せるか聞く | 2026-11-25 | 未着手 |
| Perlコミュニティ | 保守の困りごと・紹介可能性を探る | 2026-11-29 | 未着手 |

※実際の候補企業への発注・紹介・商談が確認できたという意味ではありません。

## 非公開で使う管理テンプレート

- 見込み先ID / 会社名
- 事業との関係 / 情報源
- 課題（発言に基づく事実）/ 仮説（推測）
- 最終連絡日時 / 相手の反応
- 次の行動 / 期限
- 提案価格 / 結果

**実運用の台帳には顧客・見込み先の情報が含まれ得るため、ここに書かないでください。**
